# 酒店管理系统

## 📌 项目简介
本项目是一款纯前端实现的轻量化酒店住宿管理应用，面向酒店前台办公场景，覆盖房间管理、价格管理、客人管理、房费结算四大核心业务，完整支持「入住登记-在住消费-退房结算-房态更新」全流程闭环。项目基于华为云码道（CodeArts）代码智能体AI辅助开发，采用原生 HTML + CSS + JavaScript 技术栈，无需后端服务与构建工具，开箱即用，所有业务数据通过浏览器本地存储持久化保存。

项目兼具业务实用性与工程化规范，可直接用于中小型酒店日常运营管理，也可作为前端开发、业务系统设计与AI辅助开发的学习参考案例。

## ✨ 核心特性
- **业务全闭环**：完整覆盖酒店前台核心运营流程，房态自动联动流转，计费规则灵活可配
- **开箱即用**：纯静态项目，零依赖、零安装，浏览器直接打开 `index.html` 即可运行
- **工程化架构**：代码按职责分层拆分，样式与逻辑解耦，目录结构清晰，易于维护扩展
- **办公友好UI**：采用浅色商务风格设计，高对比度信息呈现，降低长时间操作视觉疲劳
- **精细化排版**：针对不同字段类型采用差异化对齐规则，数值右对齐、文本左对齐、表头居中，提升信息读取效率
- **数据持久化**：基于 localStorage 实现本地数据存储，刷新页面数据不丢失，支持导入导出备份

## 🛠️ 技术栈
- **前端框架**：原生 HTML5 + CSS3 + JavaScript（无第三方框架依赖）
- **数据存储**：localStorage 浏览器本地持久化
- **布局方案**：Flex + Grid 响应式布局
- **开发工具**：华为云码道 CodeArts 代码智能体

## 🚀 快速开始
### 方式一：直接运行
1. 下载/克隆本项目到本地
2. 直接用 Chrome / Edge 等现代浏览器打开 `index.html` 文件即可使用

### 方式二：本地服务运行
```bash
# 进入项目目录
cd HotelManagement

# 使用任意静态文件服务启动，例如：
python -m http.server 8080
# 访问 http://localhost:8080 即可
```

## 📦 功能模块
### 核心业务模块
1. **房间管理**：支持房间信息增删改查，按房型/楼层/状态多条件筛选，房间状态全生命周期管理（空闲/已入住/清洁中/维修中）
2. **价格管理**：按房型配置基础房价，支持周末价格系数、长住优惠、特殊日期定价，可视化规则配置
3. **客人管理**：客人档案全生命周期管理，支持历史入住与消费记录查询，老客信息一键复用
4. **房费结算**：自动按天精准核算房费，支持额外消费登记、押金抵扣、半天房费规则，生成明细账单与打印输出

### 辅助功能
- 数据看板：实时展示入住率、营收、房态等核心运营指标
- 快速入住/退房：一站式前台操作入口，简化高频业务流程
- 历史记录：入住记录与结算记录双维度查询
- 数据管理：支持全量数据JSON格式导入导出，一键备份恢复

## 🎨 设计特点
- **主色调**：商务蓝 `#165DFF`，贯穿核心操作与重点信息，专业稳重
- **状态色规范**：空闲绿色、已入住红色、清洁中橙色、维修中灰色，高辨识度一眼可辨
- **排版规则**：告别清一色左对齐，表格表头居中、数值右对齐、文本左对齐，兼顾美观与信息读取效率
- **交互优化**：统一 Toast 轻提示、表单实时校验、模态框快捷关闭、表格分页，提升操作体验
- **打印适配**：专属账单打印样式，输出规范清晰的酒店结算单据

## 📝 注意事项
1. 业务数据存储在浏览器本地 localStorage 中，清除浏览器缓存或更换浏览器会导致数据丢失，建议定期导出备份
2. 推荐使用 Chrome 90+ / Edge 90+ 及以上版本现代浏览器访问，以获得最佳体验
3. 本项目为纯前端实现，适合小规模场景使用，大规模生产环境建议搭配后端服务与数据库使用
