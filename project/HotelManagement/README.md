# 酒店住宿管理系统

一个基于纯前端技术的酒店住宿管理系统，无需后端服务，直接在浏览器中运行。

## 项目简介

本系统面向酒店前台工作人员，提供完整的酒店住宿管理功能，包括房间管理、客人管理、入住登记、退房结算、价格配置、数据统计等功能。系统采用浅色商务办公风格设计，降低长时间操作的视觉疲劳，强化关键信息辨识度。

## 功能特性

### 核心功能

- **数据看板**：实时统计经营指标、今日在住列表、快捷操作入口
- **房间管理**：房间增删改查、状态流转（空闲→已入住→清洁中→空闲）
- **价格管理**：基础房价配置、周末价格系数、长住优惠规则、特殊日期价格
- **客人管理**：客人档案管理、身份证/手机号格式校验、历史记录查看
- **快速入住**：空闲房间选择、客人信息录入、日期校验、状态联动
- **快速退房**：额外消费添加、半天房费规则、账单实时预览、支付方式选择
- **房费结算**：结算记录查询、账单详情查看、打印功能
- **历史记录**：入住/结算记录双标签页、详情查看
- **数据管理**：JSON导出/导入、数据清空、二次确认

### 技术特点

- **纯前端架构**：无需后端服务器，直接打开index.html即可运行
- **数据持久化**：使用localStorage存储，刷新页面数据不丢失
- **模块化设计**：HotelApp全局命名空间，避免全局污染
- **价格计算引擎**：支持基础房价、周末价格、长住优惠、特殊日期价格四种规则
- **状态流转机制**：房间状态机设计，保证状态流转合法性
- **数据初始化**：首次使用自动初始化示例数据，降低使用门槛

## 技术栈

- **HTML5**：语义化标签、表单控件
- **CSS3**：CSS变量、Flexbox、Grid布局、动画
- **原生JavaScript**：ES6+语法、模块化设计
- **localStorage**：数据持久化存储

## 使用说明

### 快速开始

1. 下载项目文件
2. 直接在浏览器中打开 `index.html` 文件
3. 系统会自动初始化8间示例房间和默认价格规则
4. 开始使用各项功能

### 默认数据

系统首次运行时会自动初始化以下数据：

- **示例房间**：301-308号房间，包含单人间、双人间、豪华间、套房等房型
- **价格规则**：
  - 单人间：288元/天
  - 双人间：388元/天
  - 豪华间：588元/天
  - 套房：888元/天
  - 周末价格系数：1.2
  - 长住优惠：连住3天95折、7天9折、15天85折

### 操作流程

#### 入住流程

1. 点击"快速入住"或数据看板的快捷入口
2. 选择空闲房间
3. 填写客人信息（姓名、身份证、手机号等）
4. 设置入住日期、退房日期、押金金额
5. 点击"确认入住"
6. 房间状态自动变为"已入住"

#### 退房流程

1. 点击"快速退房"
2. 选择已入住房间
3. 系统自动加载入住信息和账单预览
4. 选择支付方式
5. 点击"确认退房"
6. 房间状态自动变为"清洁中"

#### 价格管理

1. 进入"价格管理"页面
2. 配置基础房价、周末价格系数
3. 点击"保存配置"

#### 数据管理

- **导出数据**：将所有业务数据导出为JSON文件
- **导入数据**：从JSON文件导入数据（会覆盖现有数据）
- **清空数据**：清空所有业务数据（需二次确认）

## 注意事项

1. **数据存储**：所有数据存储在浏览器的localStorage中，清除浏览器数据会导致数据丢失，建议定期导出备份
2. **浏览器兼容**：推荐使用Chrome、Firefox、Edge等现代浏览器
3. **数据安全**：导入数据会覆盖现有数据，请谨慎操作
4. **打印功能**：房费结算页面支持打印，会自动隐藏非必要元素

## 开发说明

### 模块化设计

系统采用HotelApp全局命名空间，所有模块挂载在该命名空间下：

```javascript
HotelApp.storage      // 数据持久化
HotelApp.validator    // 数据校验
HotelApp.formatter    // 数据格式化
HotelApp.calculator   // 价格计算
HotelApp.room         // 房间管理
HotelApp.guest        // 客人管理
HotelApp.price        // 价格规则
HotelApp.order        // 入住订单
HotelApp.settlement   // 结算管理
HotelApp.dashboard    // 数据看板
HotelApp.ui           // UI交互
```

### 扩展开发

如需扩展功能，可以：

1. 在对应模块中添加新方法
2. 在app.js中添加页面初始化逻辑
3. 在index.html中添加页面HTML结构
4. 在对应pages目录下添加页面样式
